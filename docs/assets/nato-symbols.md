# NATO 兵牌素材

素材来源：[milsymbol 3.0.5](https://github.com/spatialillusions/milsymbol)，
MIT License。

应用生成静态 SVG 并存放在 `src/assets/nato`，运行时不依赖 milsymbol。

## 兵科与 SIDC 功能码

| 兵科 | 功能码 |
|---|---|
| 步兵 | `1211000000` |
| 装甲 | `1205000000` |
| 炮兵 | `1303000000` |
| 侦察 | `1213000000` |
| 陆航 | `1206000000` |
| 航空 | `1208000000` |
| 海军 | `1202030000` |
| 指挥 | `1100000000` |

友军使用身份位 `3` 和矩形框，敌军使用身份位 `6` 和菱形框。海军使用水域
符号集 `30`，其余陆上兵科使用符号集 `10`。素材分别输出友军绿 `#92cf00`
和敌军红 `#9b351f` 两种透明底色变体。

## 与 PSD 素材的关系

NATO 兵牌是独立素材组。用户 PSD 中的剪影、目标框和箭头保持原始结构，
不会嵌套进 NATO 框架。两类素材可在素材库和属性面板中分别选择。
