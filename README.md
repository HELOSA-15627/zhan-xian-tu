# 战线图志

本地优先的 Web 战术地图编辑器。导入自定义底图后，可以放置战役图标、绘制推进箭头和区域、添加批注，并播放箭头绘制动画。

## 功能

- 导入 PNG、JPG、JPEG、WebP 底图。
- 放置友军、敌军、指挥部、防线、巢穴、目标、装甲和航空图标。
- 绘制箭头、区域、文字和自由手绘线。
- 编辑颜色、线宽、尺寸、旋转、透明度和图层。
- 设置箭头动画延迟、持续时间和拖动时间线。
- 撤销、重做、复制和删除。
- IndexedDB 自动保存。
- 导出完整地图 PNG。
- 导出和导入 `.atlas.json` 项目文件。

## 开发

```bash
npm install
npm run dev
```

## 验证

```bash
npm run typecheck
npm test -- --run
npm run build
npx playwright install chromium
npm run test:e2e
```

端到端测试覆盖底图导入、图标和箭头绘制、动画进度、PNG 尺寸以及刷新后的本地草稿恢复。

## 数据与隐私

底图和项目只在当前浏览器本地处理。首版不连接在线地图、不上传项目，也不包含账号或云同步。

导出的 `.atlas.json` 会内嵌底图，因此文件可能较大，但也便于在其他电脑上直接重新打开。

## 视觉来源与版权边界

视觉语言参考了军事档案地图的图层组织、阵营色、防线线型和注释层级，但没有打包设定集的扫描页、角色、标志或机甲原画。应用内战术符号、界面和示例网格均为项目原创。
