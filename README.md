# 战线图志

本地优先的 Web 战术地图编辑器。导入自定义底图后，可以放置战役图标、绘制推进箭头和区域、添加批注，并播放箭头绘制动画。

## 功能

- 导入 PNG、JPG、JPEG、WebP 底图。
- 已导入地图会进入地图列表，可查看缩略图、选取当前地图、改名并调整显示参数。
- 每张底图拥有独立的图层树、对象、滤镜和等高线设置；切换当前编辑底图会切换整套标注状态。
- 多张底图可同时作为叠加栈显示，可单独隐藏、排序，并选择任意一张作为当前编辑底图。
- 按友军、敌军、目标分组放置战役兵牌。
- PSD 原画素材保持原始剪影与箭头结构，不套额外兵牌框。
- PSD 原画兵牌带黑色主体外轮廓，提升浅色纸面和复杂底图上的辨识度。
- PSD 与 NATO 兵牌描边默认开启，可在兵牌属性中单独关闭。
- 兵牌描边宽度可调；箭头头部可缩小到 0，不再强制最小尺寸。
- 独立导入 NATO APP-6 兵科素材，友军矩形、敌军菱形，阵营底色保持完全不透明。
- PSD 素材提供友军、敌军、目标三套纯色透明版本，去除边缘浮色。
- 箭头支持直接拖动和逐点折线两种绘制模式；直接模式使用平滑笔势，折线模式使用直线段和尖角连接。区域支持直接拖动闭合和逐点折线闭合。
- 箭头和手绘线支持推进带、计划虚线、防线双轨、警戒点线、阶段线、边界点划和栅栏防线。
- 虚线、点线、阶段线和点划线可按名称设置段数，区域边界同样支持段数调节。
- 提供指挥细笔、标绘笔、推进宽笔和渐细笔四种新对象笔刷预设。
- 手绘和箭头带可调强度的指针防抖；直接箭头使用开放曲线平滑，折线箭头保持尖锐弯折。双轨线保持两条独立开放路径。
- 箭头和手绘线可分别设置总宽度、起点宽度和终点宽度，形成均匀笔触或楔形笔触。
- 箭头头部大小可独立于线宽调整，并提供 PSD、三角、燕尾和枪尖四种样式。
- 箭头动画的箭头始终位于当前线头，并沿实际路径切线旋转；线杆与箭头底边精确衔接。
- 兵牌支持不透明度，默认 100%，PSD 与 NATO 兵牌均可单独调整尺寸。
- 区域使用实心直线边界，拐角保持尖角且不显示节点圆点；边框与半透明填充同色并可实时修改。
- 区域工具可直接点击既有闭合区域内部完成选择，不必先切换到选择工具。
- 区域支持自定义、矩形、椭圆、菱形预设，以及实线、虚线、点线边界；虚线和点线可调整段数。
- 地图底部的 47 面国家国旗已作为独立素材组导入，素材库和搜索使用中文国名，放置时不自动添加批注。
- 原图巢穴仅对主体外轮廓做抗锯齿平滑，保留内部细节、原始颜色和透明缺口。
- 素材库支持按中文或英文名称同时搜索 PSD、NATO 兵牌和国旗。
- 可导入自定义外部兵牌；图层或图层组可按名称保存为图形素材，并在“自定义”素材组中重复调用。
- 兵牌和区域可整体拖动；闭合区域支持闭锁，锁定时仍可拖动，解锁后可沿边界插入节点。
- 拖动对象时显示与附近对象的像素间距辅助线。
- 每个图层可单独隐藏或显示，隐藏状态会在图层行明确标记。
- 图层支持编组和嵌套显示；隐藏或锁定父级群组会作用于全部子图层。
- 标注图层下可直接新建子图层；任意深度的图层或图层组都可编组、隐藏、锁定和保存为图形素材。
- 图层支持改名、透明度、前后排序，以及对象在同层内前后移动或迁移到其他图层。
- 对象拖动时实时显示当前位置，松开指针后才写入一条撤销历史。
- 选中对象后可拖动四角手柄，分别改变水平轴和垂直轴尺寸；兵牌与文字使用独立横纵缩放。
- 选中对象后可拖动顶部旋转手柄，或使用属性面板进行左右 90° 旋转与水平/垂直翻转。
- 地图批注默认带浅色描边，可在文字属性中单独关闭，关闭后只保留文字主体颜色。
- 地图批注可选择常见系统字体；浏览器支持 Local Font Access 时可读取本机已安装字体，也允许手动填写字体名。
- 底图支持可调虚化和噪点滤镜；可手动生成亮度等值线并切换显示，生成结果随项目保存在本地。
- 交互编辑时虚化与噪点会离屏烘焙为缓存底图，缩放和拖动不再反复重算整图滤镜或全图噪点混合；默认参数不创建额外合成层。
- 等高线生成后缓存为单张透明栅格图，缩放时不再反复处理巨型 SVG 路径；蓝色河流和水体默认从等值线分析中排除。
- 编辑颜色、线宽、尺寸、旋转、透明度和图层，颜色变化会同步反映在线型预览和画布对象上。
- 设置箭头动画延迟、持续时间和拖动时间线。
- 撤销、重做、复制和删除。
- IndexedDB 自动保存。
- 导出完整地图 PNG。
- 导出和导入 `.atlas.json` 项目文件。

## 开发

```bash
npm install
npm run dev
```

```bash

npm run build
npx playwright install chromium
npm run test:e2e
```

端到端测试覆盖底图导入、多底图独立状态与叠加显隐、直接与折线绘制、动画箭头跟随、兵牌透明度、新线型与笔刷、区域闭锁拖动与解锁加点、图层编组、自定义兵牌、图形素材调用、栅格等高线、底图滤镜、PNG 尺寸以及刷新后的本地草稿恢复。

## 数据与隐私

底图和项目只在当前浏览器本地处理。首版不连接在线地图、不上传项目，也不包含账号或云同步。

导出的 `.atlas.json` 会内嵌底图，因此文件可能较大，但也便于在其他电脑上直接重新打开。

## 视觉来源与版权边界

视觉语言参考了用户提供的军事档案地图、兵科图例和战线示意页，归纳其
NATO 兵牌、宽色带推进线、双轨防线、编号圆章和斜切说明卡。项目没有打包
设定集扫描页、角色或作品标志；透明 PNG 来自用户提供的 PSD 图层，
NATO 兵牌为单独生成的 SVG 素材组。
